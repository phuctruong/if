## Why this exists

Every Solace tenant repo follows the same shape so workers reading the
context-DB at runtime don't have to handle drift across tenants. IF Theory
is a research project rather than a customer, but it lives inside the same
canonical structure so its canon files are syncable to Firestore, its
diagrams are auditable, and its evidence chain is queryable from
solaceagi.com the same way Gatan's or Metalmark's are.

## RESERVED paths (don't put other things here)

| Path | What goes here | What doesn't |
|---|---|---|
| `canon/` | Authored project specs (this canon-parity set) | Source data, raw notebook outputs, anything autogenerated |
| `audits/` | Live + transcribed audit scripts and their provenance JSON | Output artifacts (those go in scratch/) |
| `evidence/replications/` | Future: one file per external reproduction attempt | Anything that isn't an external reproduction record |
| `scratch/` | Local-only experiment output | Anything committed to git |

| State | Trigger | Cost |
|---|---|---|
| `BAO_TENSION_HIDDEN` | Citation of DESI DR1 BAO global fit without χ²/dof = 1.72, p = 0.034, 2.1σ | BLOCK |

| `CONVERGENCE_CLAIM_WITHOUT_R_P_CERTIFICATE` | Any "converges" claim without halting certificate at rung 274177 | BLOCK |
| `FLOAT_IN_PROOF_PATH` | `float` used where `Fraction`/`Decimal` is required | BLOCK |
| `SILENT_FALLBACK_IMPORT` | `except ImportError:` in `predictions/*.py` | BLOCK (caused σ₈ drift in earlier versions) |
| `ZERO_PARAM_OVERCLAIM` | "Zero free parameters" claim without "zero NEW parameters on top of Planck 2018" qualifier | BLOCK |
| `MERSENNE_VERIFIED_OVERCLAIM` | Output of `mersenne_tower_theorem.py` claims "VERIFIED" instead of "OPEN" for the uniqueness lemma | BLOCK |
| `ACADEMY_DEFERENCE` | Adding "peer review pending" hedges to working code or canon docs (per operator memory 2026-05-17) | WARN |

## What gets synced where

```
canon/*.md (top-level)        →  companies/if/canon/<slug>             via solace-sync.sh --only canon
                                  AND companies/if/wiki_pages           via sync_canon_to_wiki.py
canon/falsifiers/*.md         →  companies/if/falsifiers/<name>        via solace-sync.sh --only falsifiers
evidence/replications/*       →  companies/if/evidence/replications/   (operator-initiated only)
README.md / NORTHSTAR.md      →  NEVER synced — top-level pointers, not canonical
papers/                       →  NEVER synced — academic artifacts, lives in git for provenance
notebooks/                    →  NEVER synced — large + reproducible from source
bao_data/, euclid_data/       →  NEVER synced — data caches, gitignored beyond pointers
scratch/                      →  NEVER synced + gitignored
```

## When you find drift

A repo violating this standard is one of:
- **Legacy** — predates this doc. File a cleanup task; tolerate short-term.
- **Bug** — operator put a thing in the wrong place. Move it; update lint.sh.
- **Better idea** — operator found a layout improvement. Update THIS DOC first
  (LAI-22 diagram-first), then propagate to other research-project tenants.
